This repo contains code supporting the paper "A comparison of 2-bit quantisation techniques: RaBitQ, TurboQuant, and EVP"

There is code written in MatLab, Python and C++

The majority of the analytical code is in MatLab in the form of .mlx files.
You don't need a MatLab licence to access these, they are just zip files containing matlab code and other content.
You probably do need a licence to run them...

The get_data function will work for uniform hyperspherical data, for the named data set
they are not included for reasons of space but you just need to download the 
.h5 files somewhere and change the embedded file path.
